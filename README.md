# **BHetland's Snippets**

This repository does not contain any "real" source code!
In here I only collect some random code snippets in order to
* demonstrate some feature
* test various implementations and environments
* illustrate how something can be done
* make a _note_ of something hopefully worth remembering

The programs have no organized way of building. Some of them may in fact be intended to be played with by various alterations to the code in order to learn or discover the concept or idea.

The whole repo is basically a notebook that I choose to share with
the world and anyone curious enough to bother looking.
